# YtDlpGui

yt-dlp を GUI から簡単に使うための動画ダウンロードアプリです。
URL を貼り付けて、画質・音質・形式を選んでダウンロードするだけで使えます。


## 動作環境

- Windows 10 / 11 (64bit)
- インターネット接続（初回起動時と、動画ダウンロード時に必要です）
- .NET のインストールは不要です（アプリ単体で動作します）


## インストール方法

1. `YtDlpGuiSetup-x.x.x.exe` をダブルクリックして実行します。
2. 案内に従って進めれば完了です。管理者権限は不要です。

### Windows SmartScreen の警告が出た場合

このアプリには署名証明書を付けていないため、初回実行時に
「WindowsによってPCが保護されました」という青い画面が出ることがあります。
これは未知の発行元のアプリに対する標準的な警告で、悪意のあるプログラムという
意味ではありません。

画面内の **「詳細情報」** をクリックし、表示される **「実行」** ボタンを
押すとインストール（または起動）できます。


## 初回起動時について

初回起動時、必須ファイル（yt-dlp / FFmpeg / FFprobe / Deno）が
自動的にダウンロードされます。この間は画面下部のステータス欄に
進捗が表示され、「情報取得」「キューに追加」「ダウンロード開始」の
ボタンは準備が完了するまで押せません。

この処理にはインターネット接続が必要です。ネットワークが無い環境や、
ダウンロードに失敗した場合は、設定画面から手動で更新できます。


## 基本的な使い方

1. URL欄に動画（またはプレイリスト）のURLを貼り付けます。
2. 画質・音質・形式を選びます。
3. 「キューに追加」を押します。
   - プレイリストのURLを追加した場合、中の動画が自動的に
     個別のキュー項目として展開されます。
4. 保存先を選択し、「キュー開始」でダウンロードが始まります。
5. 1件が失敗しても、他の項目のダウンロードは続行されます。
   失敗した項目は「再試行」できます。


## 設定・ダウンロード済みファイルの保存場所

このアプリは以下のフォルダにのみ設定やツールを保存します。
アプリ本体をインストールしたフォルダには何も書き込みません。

```
%LOCALAPPDATA%\YtDlpGui
```

（エクスプローラーのアドレス欄に `%LOCALAPPDATA%\YtDlpGui` と入力すると開けます）


## アンインストール方法

「設定」→「アプリ」からアンインストールできます。

なお、アンインストールしても上記の `%LOCALAPPDATA%\YtDlpGui`
フォルダ（設定・yt-dlp/FFmpeg/Denoなど）は自動では削除されません。
再インストール時にツール一式を落とし直さずに済むようにするための
仕様です。完全に削除したい場合は、アンインストール後に
このフォルダを手動で削除してください。


## 注意事項

- 動画のダウンロードは、対象サービスの利用規約や著作権法の範囲内で
  行ってください。
- 本アプリは yt-dlp / FFmpeg / Deno を利用しています。それぞれの
  ライセンスに従います。
